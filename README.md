# Kabristan Committee Management System

A private, bilingual (English/Urdu) mobile application for managing family memberships, contributions, receipts, and burial records for a community graveyard committee.

- Stack (proposed): Flutter, Supabase (PostgreSQL, Auth, Row-Level Security)
- Platforms: Android and iOS, privately distributed
- Data: sensitive. This repository must only ever contain fictional data.
